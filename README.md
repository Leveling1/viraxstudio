# ViraxStudio

Automatise ta chaine YouTube de A a Z.

Live : https://viraxstudio.levelingcoder.com

## Stack
- React 18 + Vite + React Router v6
- GitHub Actions -> FTP -> o2switch
- Claude API, ElevenLabs, YouTube Data API v3

## Secrets GitHub Actions
- FTP_SERVER
- FTP_USERNAME
- FTP_PASSWORD
- FTP_SERVER_DIR
- VITE_GOOGLE_CLIENT_ID
